# Recommended Order
- Phase 1 (Weeks 1–3): Arrays, Two Pointers, Sliding Window, Stack, Linked List.
- Phase 2 (Weeks 4–6): Binary Search, Trees, BFS/DFS, Backtracking.
- Phase 3 (Weeks 7–10): DP (all categories) + Greedy + Intervals.
- Phase 4 (Weeks 11–12): Advanced Graphs, Heap, Trie, Monotonic Stack, Bit Manipulation.

Solve at least 5–7 problems daily — re-solve the medium/hard ones after 2 weeks to reinforce retention. Use the "Neetcode" order or sort by frequency on LeetCode for extra confidence.
